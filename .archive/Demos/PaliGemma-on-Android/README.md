# PaliGemma 安卓高頻
該儲存庫是在 Android 上使用 Hugging Face-Gradio 用戶端 API 推斷 PaliGemma 視覺語言模型的實現，用於零樣本目標檢測、圖像字幕和視覺問答等任務。
