# Gemma

該資料夾分為幾個類別，每個類別都專注於使用 Gemma 模型的特定方面：
* [推論與服務](#inference-and-serving) : 如何為inference載入、執行和部署Gemma模型
* [提示](#prompting) : 探索各種prompting 技術
* [RAG（檢索增強生成）](#rag)：如何使用Gemma構建RAG系統
* [微調](#finetuning) ：深入研究特定任務和領域的 finetuning Gemma 模型
* [Alignment](#alignment)：對齊Gemma模型的技術
* [評估](#evaluation) : 如何評估Gemma模型
* [Agentic AI](#agentic-ai) : 如何使用Gemma模型建立智慧agents
